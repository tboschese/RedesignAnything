# Feature names

Name checks for user-visible feature names, as [standards/naming.md](https://github.com/storytold/craft-contrib/blob/main/standards/naming.md) rule 4 asks. A row records a policy choice, not a finding that a name infringes anything, and not trademark clearance.

## Redesign modes (2026-11-20)

The stored ids `refresh`, `redesign` and `reimagine` come from `REDESIGN_SPEC/CONTRACTS.md` and are not shown as labels.

| Label | Mode id | Decision | Why |
| --- | --- | --- | --- |
| Reimagine | `reimagine` | Not used | Another company uses it as the name of its own photo-editing feature. |
| Tidy up | `refresh` | Not used | Figma names a feature "Tidy up" ([help article](https://help.figma.com/hc/en-us/articles/360040450233)); a web search did not find three unrelated products using it descriptively for their own feature. |
| Rethink | `reimagine` | Not used | A web search of US register aggregators shows live `RETHINK` registrations for software (for example [Reg. 1985158](https://trademarks.justia.com/746/20/rethink-74620092.html), class 9). |
| Organize screens | `refresh` | Used | A plain description of what the mode does. A web search found it only as descriptive wording in another product's tagline, and no registration. |
| Redesign journeys | `redesign` | Used | A plain description. A web search found it only as a service description. |
| New flows | `reimagine` | Used | A plain description. A web search found it only as generic wording. |

**Confirmed by the operator:** on 2026-11-20 the operator confirmed the three labels in use (Organize screens, Redesign journeys, New flows). That is a choice of wording, not trademark clearance.

**How it was checked:** general web searches on 2026-11-20. The USPTO, EUIPO or TMview, and WIPO Global Brand Database were **not** searched directly; whoever ships these labels in a UI runs those searches and updates this table.
